# 后续计划

## 后续功能

- 桌面混合开关
- 多点触控支持

## 暂缓或不做

- GPU 资源预热、MeshTri 包围盒半径缓存和 uniform 位置缓存：当前收益不足以优先处理。
- 广色域 / HDR 的实机观感验收：色域矩阵与传递函数已通过离屏 GPU 对照，仍需面板、ICC 与驱动组合验证。
- Ring4 类型迁移、OBJECT library 重构和其他 draw call 合并：不带来足够运行时收益。
- 洋红色 DebugDamage、点击实例数量上限、截图回归测试和更多用户参数：可能改变行为
  或增加维护成本。
- 低分辨率 Bloom、持久映射 VBO、几何缓存、Shader 缓存和跨发行版二进制打包：现有
  性能数据没有显示足够收益。
- MeshTri 静态网格展平，预计只减少少量 CPU 微秒，暂不值得优先做

## 原版等价验收
